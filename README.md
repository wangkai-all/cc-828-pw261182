# 计量方差工作台

同一产品在多家实验室、多台设备、不同日期重复测量时，误差来源彼此交叉。把每一层的样本方差直接相加，会重复计入共享成分、丢掉交互项，得到的“不确定度预算”并不是这个设计的。这个工作台把重复设计当作一个整体：显式写出交叉/嵌套关系，用带非负约束的 REML 联合估计方差分量，报告哪些分量在这个设计下根本不能分离，再用当前精度比较下一笔预算的不同花法，并用一轮模拟测量去核对预测。

## 模型与设计约定

每个测量记为 `(lab, device, date, value)`，同一 `(lab, device, date)` 单元可以有多条重复。

* **设备嵌套于实验室**：设备编号只在实验室内唯一，模型里的水平键是 `lab/device`。
* **日期与实验室交叉**：同一日期可以由多家实验室测量，这是把实验室效应与日期效应分开的唯一途径。
* **可选交互**：`lab:date`（交叉）与 `device:date`（嵌套交互）。
* **残差**：同一单元内的重复测量，`σ²` 由单元内平方和识别。

可勾选的随机项：实验室、设备、日期、实验室×日期、设备×日期（按需组合）。

### 为什么不能逐层相加

嵌套的设备效应已经包含在实验室的重复测量里，日期又跨实验室；按层级把方差相加既重复计算，也无法表达“日期在不同实验室之间的偏移”。协方差结构必须同时拟合。工作台用 REML 在单元均值归约上联合估计全部随机项：

```
ybar_b = mu + Σ_k u_k[level_k(b)] + ebar_b ,   Var(ebar_b) = σ² / m_b
V = Σ_k θ_k Z_k Z_k' + σ² diag(1/m_b)
```

单元内部分贡献 `(N−B)·log σ² + SSw/σ²`，因此残差即便在没有重复时也能通过模型结构部分识别（但会在诊断中提示）。

## 可分离性诊断

拟合之前先诊断，分三档：

1. **错误（阻止拟合）**
   * 实验室–日期二部图不连通：组间没有共享的实验室或日期，`lab:date` 与主效应混在一起。
   * 随机项的协方差结构（`vec(Z_k Z_k')`）线性相关：例如每个实验室只有 1 台设备时，实验室与设备吸收同一个水平。
2. **警告**：局部混杂但整体可估，例如某台设备只在一个日期测量。
3. **说明**：单元内重复使残差与随机项在总变异上存在一个可抵消方向，但单元内平方和单独识别残差，因此不是冲突。

设计页的**连接图**把实验室与日期画成二部图，边宽表示该组合的测量条数，悬停可见设备数；连通组数直接对应报告里的“不可分离”结论。

## 非负边界

方差分量约束为 `θ_k ≥ 0`，残差用 `log σ²` 参数化，因此协方差矩阵始终严格正定。**不会为了求逆而给协方差加任何常数**；数值上不可用的试探点会被目标函数拒绝（返回大罚值），而不是被修补。落到 0 的分量：

* 拟合结果标注 `at_boundary`；
* 区间改为单侧的剖面似然区间（`0.5χ²₀ + 0.5χ²₁` 临界值）；
* 报告 KKT 方向导数，便于核对约束是否真的在最优点上。

优化器对 `θ` 设了一个由数据尺度决定的上界。这是一个**搜索框**（避免 L-BFGS-B 跑到数值上退化的区域），不是加进协方差的常数；上界远高于任何合理解，测试会核对它不改变最优解。

## 区间

* 每个随机项：剖面似然区间。内部解用 `χ²₁` 临界值；边界解用单侧 `0.5χ²₀ + 0.5χ²₁`。
* 残差：有重复时用单元内平方和的精确缩放卡方区间；无重复时退化为剖面的渐近区间。

## 预算情景

预算页只买**未来的**测量，已有测量的成本是沉没成本，既不重复计入，也不从可支配预算里扣除。三档价格对应三种杠杆：

* 新增实验室（含首台设备，在其上按共享日期测量）；
* 新增设备（只用于在已有实验室内追加设备）；
* 新增测量（每条测量计价，不管落在已有单元还是新的设备–日期组合）。

每种安排的精度不是经验公式，而是把这个假想设计**实际构造出来**，用拟合出的分量做 GLS，求总体均值的方差：

```
Var(μ̂) = 1 / (1' V⁻¹ 1)
```

枚举在预算内可行的组合，按预测精度排序；`best` 是最优一行。

**目标精度。** 预算输入里可以填一个目标均值标准误（留空则不设）。`design.target_progress` 据此回答三件事：

* 当前设计是否已经达标（是则本轮可以不花钱）；
* 若不达标，预算内**最便宜的达标方案**是哪一个、花多少；
* 若预算内最好的方案仍达不到，还差多少（`shortfall`），好让用户去提高预算或放宽目标。

它比较的是预算内枚举出来的方案，因此“达标”始终附带价格约束；表里的“目标”列与图中的虚线只是把同一个判断搬到每一行上。目标值本身只影响比较，不改变任何方差分量的估计。

## 验证轮

验证页按拟合出的分量模拟一轮新测量（同一个模型、同一个设计），重新拟合，然后对比：

* 预测的均值标准误 vs 模拟中 `μ̂` 的实际离散度（比值落在 0.75–1.3 视为一致）；
* 每个分量的偏差、模拟标准差、Wald 区间覆盖率、落到边界的频率；
* 第一轮模拟的原始新增测量作为样例展示。

验证循环里用 Wald 近似区间（比逐轮跑剖面似然快得多）；主拟合页展示的仍是剖面似然区间。单轮拟合失败（例如极端抽样的数值问题）会被计入并跳过，不会悄悄修补数据。

## 手算核对

拟合页与追溯页会对平衡设计给出 ANOVA 矩估计并逐项对比 REML：

* **嵌套**：`lab > device`，每台设备只在一个日期测量。
  `σ²e = MSe`，`σ²device = (MSdev − MSe)/n`，`σ²lab = (MSlab − MSdev)/(n·B)`。
* **交叉**：完整的 `lab × date`，每台设备在每个日期测量。
  含交互时 `σ²lab:date = (MSint − MSe)/n`，`σ²lab = (MSlab − MSint)/(n·B)`，`σ²date = (MSdate − MSint)/(n·A)`。

非平衡或结构不符时明确返回“不能手算”及原因，而不是给一个误导性的数。ANOVA 矩估计允许负值（作为诊断），REML 估计则被约束在边界上。

## 虚构预设

首页的四个预设都是固定种子、已知真值的可复现设计：

| 预设 | 布局 | 用途 |
| --- | --- | --- |
| `nested_clean` | 4 实验室 × 2 设备 × 每单元 3 次 | 设备嵌套，实验室/设备/残差全可分离 |
| `crossed_lab_date` | 6 实验室 × 4 日期 × 3 次 | 交叉含 `lab:date`，与手算对齐 |
| `crossed_disconnected` | 两组实验室各测各的日期 | 应报告“不可分离”，阻止拟合 |
| `boundary_zero` | 4 实验室 × 3 日期，日期真值为 0 | 检查非负边界与单侧区间 |

## 可追溯性

每个项目是一个 JSON 文件，包含测量行、模型项、设置、最新结果与**只追加不修改**的审计轨迹。每条事件带 UTC 时间、数据指纹（SHA-256 前 16 位）、输入与关键输出。CSV/JSON 可随时导出，审计轨迹在“追溯”页按发生顺序读取。
